Detailed Description

Item model over all waypoints known to the app, for search lists.

Rows are the waypoints of the WaypointLibrary (the user's own waypoints, first), followed by the waypoints of the installed aviation maps. Both groups are sorted by name. Library changes are forwarded row by row; a change of the aviation data replaces the map rows in a single reset.

The role 'searchKey' holds Librarian::simplify(name) + " " + Librarian::simplify(ICAO code). For the map rows it is precomputed on the worker thread that reads the aviation data, so that a NameFilterProxyModel with filterRoleIsSimplified can filter tens of thousands of rows on every keystroke without normalising a single name:

model: NameFilterProxyModel { sourceModel: WaypointSearchModel {} filterRoleName: "searchKey" filterRoleIsSimplified: true filter: textInput.filter }
